# javascript-mini-project-01

## 🎉 New Year Countdown 🎆
A responsive and elegant **New Year countdown timer** built using **HTML, CSS (Bootstrap 5)**, and **JavaScript**. It dynamically counts down to January 1st of the upcoming year, updating every second.

## 🔧 Features
- ⏳ Real-time countdown (Days, Hours, Minutes, Seconds)
- 📱 Fully responsive for mobile and desktop devices
- 🌄 Background image with dark overlay using `linear-gradient`
- ⚙️ Automatically detects and displays the next year
- 🧱 Built with Bootstrap 5 for layout and styling

## 🚀 Technologies Used
- **HTML5**
- **CSS3** (with Bootstrap 5)
- **JavaScript**
